# Архитектура

Ориентиры по стилю: `GPU-manager-backend` (router/service/repository, Unit of Work) и `simpleOrderServiceGo` (интерфейс репозитория, явная сборка зависимостей). Исходники этих проектов не копируются.

Зависимости направлены внутрь:

```text
presentation → application → domain
infrastructure → application → domain
main → сборка адаптеров и сервисов
```

Domain содержит сущности и правила без FastAPI, Pydantic и SQLAlchemy. Application содержит сценарии авторизации, подготовки аналитики и импорта, а также порты хранилища, криптографии и модели. Infrastructure реализует эти порты через SQLAlchemy/PostgreSQL, Argon2/PyJWT и HTTP-клиент модели. Presentation переводит OpenAPI-запросы в вызовы сервисов. SQL не выходит за пределы инфраструктуры.

Состояние сессий, версий материалов, задач, сводок, диалогов и обратной связи сохраняется в PostgreSQL. Фоновые задачи исполняет worker с атомарным захватом записи. Клиент опрашивает `/jobs`, а затем загружает неизменяемый результат.

Фронтенд сохраняет исходные HTML/CSS и JS-модули из предоставленного `alfa-pulse.zip`. API-адаптер работает с контрактом `/api/v1`, преобразуя модели только для существующих компонентов отображения. Пользовательские основания, банковская аналитика и трассировка берутся с сервера.

SQLAlchemy-модели авторизации вынесены в инфраструктуру. Аналитические агрегаты хранятся версионируемыми JSONB-документами с индексом; это сохраняет изменяемые снимки схемы без привязки domain к ORM, но не заменяет специализацию таблиц при росте нагрузки. Все изменения сервиса проходят через асинхронный Unit of Work. Конкурентные операции с сессиями, идемпотентностью, импортом и бюджетом используют транзакционные advisory locks. Worker захватывает запись через `FOR UPDATE SKIP LOCKED`, продлевает lease и проверяет его перед публикацией результата.

HTTP-адаптер валидирует запросы по единому OpenAPI-файлу и переводит прикладные ошибки в согласованные ответы. Дублирующий набор Pydantic DTO не поддерживается параллельно с контрактом; соответствие ответов проверяется интеграционными тестами. OpenAPI отдается самим API и хранится в репозитории в YAML/JSON.

Выборы сверены с официальными руководствами: [FastAPI JWT/Argon2](https://fastapi.tiangolo.com/tutorial/security/oauth2-jwt/), [отдельная AsyncSession для задач SQLAlchemy](https://docs.sqlalchemy.org/en/20/orm/extensions/asyncio.html), [Alembic](https://alembic.sqlalchemy.org/en/latest/tutorial.html), [зависимости готовности Compose](https://docs.docker.com/compose/how-tos/startup-order/).
